# API implementation contract
Canonical machine-readable definition: ../contracts/openapi.json (OpenAPI 3.1). Prefix /api/v1. UUID resource IDs; workspace is explicitly in path, actor identity from auth, not request body. Health outside versioned prefix. Roles: viewer read/list/export; editor and owner mutate scenarios, runs and benchmarks. Membership provisioning outside MVP API (seed local or trusted OIDC provisioning), no role escalation endpoints. Authentication errors 401, insufficient role 403, unknown/cross-workspace resource 404, stale/invalid transition 409, invalid input 422, quota 429, unavailable 503. Error envelope {code,message,request_id,details:[{path,message}]}. Cursor pagination limit 1–100 default 50; opaque cursor stable (created_at,id) and scoped to endpoint/filter, never offset. Events use numeric after_seq and ascending seq. 
All resource creation and fault/cancel commands require Idempotency-Key (1..128 chars). Same key and same normalized request -> same response, different request ->409. Scope by workspace, authenticated actor, operation including resource ID. No retry with changed body. GET is safe. POST scenarios returns 201; validate returns 200 with valid/issues; POST runs/benchmarks/commands/cancel returns 202. Archive POST returns updated scenario; no hard delete.

## Example scenario config
```json
{"schema_version":1,"width":12,"height":8,"obstacles":[{"x":5,"y":3}],"robots":[{"id":"r1","start":{"x":1,"y":1},"zone":"west"},{"id":"r2","start":{"x":8,"y":1},"zone":"east"}],"zones":[{"id":"west","min_x":0,"max_x":5,"min_y":0,"max_y":7,"leader":"r1"},{"id":"east","min_x":6,"max_x":11,"min_y":0,"max_y":7,"leader":"r2"}],"tasks":[{"id":"t1","pickup":{"x":1,"y":2},"dropoff":{"x":4,"y":5},"release_tick":0,"priority":5},{"id":"t2","pickup":{"x":8,"y":2},"dropoff":{"x":9,"y":5},"release_tick":0,"priority":5}],"network":{"default_delay_ticks":1,"default_drop_rate":0,"links":[]},"faults":[{"type":"controller_outage","start_tick":5,"end_tick":20}],"duration_ticks":100,"tick_ms":1000,"scope_lease_ticks":40}
```
Empty network.links means fully connected directed baseline including controller C; overrides specify individual directed links. Zone rectangles nonoverlapping, leader belongs to zone; tasks scoped by pickup, cross-zone requires controller. IDs strings 1–64 safe characters; reserved controller ID C. Config validation beyond JSON Schema is application responsibility. Robot capability tags optional; all robots homogeneous P0. 
Create run: POST /workspaces/{w}/runs with {scenario_id,revision,algorithm,seed,mode:"scripted"}. Response Run includes id/status/manifest_hash/last_seq/last_tick and links derivable from id. Manifest includes config_hash, engine_version (git commit or build digest), config, policy params, seed and mode, excludes run ID/wall time. 
SSE: GET /workspaces/{w}/runs/{r}/stream?after_seq=42; Last-Event-ID header takes precedence, validated nonnegative integer. Content-Type text/event-stream; Cache-Control no-cache; event id is committed seq; data JSON Event; event name equals Event.type; heartbeat comment every 15 sec; do not send fake events; poll DB for new events with bounded batch and close after terminal status and drain. Terminal queued-cancelled or worker-lost may lack engine event; API sends unnumbered transport event stream.closed with status, clients fetch run metadata. If cursor ahead or pruned return 409 reset_required before response; reconnect after latest snapshot. Backpressure disconnect slow clients; no unbounded per-client buffers. Auth same-origin session or fetch streaming with bearer header; native EventSource cannot set Authorization. 
GET snapshot?at_seq= optional latest checkpoint <= requested; initial not available until seq1 ->409. Fetch events after returned snapshot seq, apply in order. GET metrics returns 409 until terminal metrics exist; failed/cancelled may have partial metrics only if worker produced them, mark incomplete. Export format=json returns manifest+metrics and ordered events (bounded by limits; streamed response), format=csv returns metrics rows not full event stream. Benchmark comparison schema includes aggregate by algorithm, per-run metrics/status and paired comparisons relative to centralized if present, else first listed algorithm, with missing seed counts. 
Scope revision R0: R6 will add proposed agent plan, approval, session and evidence-report endpoints plus /mcp, using the same application services. See agent-platform.md and contracts/agent-tools.json. Existing OpenAPI remains the current baseline; these endpoints are not implemented or machine-readable REST contracts yet. R6 must add and validate additive OpenAPI and MCP schemas. Derive deterministic report first, then optional advisory narrative with evidence IDs.

## R4 implementation increment (review required)
Bearer only for now; cookie alternative removed from runtime contract. Local loopback mode requires explicit randomly generated token and seeded identity; disabled by default. OIDC mode verifies RS256 signature against configured HTTPS JWKS, issuer, audience, expiry and subject; provision memberships out of band. No public anonymous access. No claim of production identity-provider interoperability until tested. Resource mutations preserve initial response in the transaction's idempotency record. Keyset cursors scoped by resource/filter. Run exports stream a fixed committed event prefix; SSE rechecks bearer and membership, supports Last-Event-ID and closes at terminal or 60-second reconnect boundary. Benchmark fanout atomic; comparisons derived from real successful matched seeds. Interactive run creation and command injection are implemented in the follow-up commit: up to 300 logical ticks and 20 commands/run, 100 ms wall pacing outside policy, apply at sampled tick, validate overlap and target, immutable manifest plus applied command trace. Scripted and terminal runs reject commands. Interactive replay is event playback only; no deterministic rerun claim. No cookie auth, no public deployment.
