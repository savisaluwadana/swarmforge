# SwarmForge

**Resilience infrastructure for physical AI.**

SwarmForge is a proposed simulation-first platform for evaluating fault-tolerant autonomous robot fleet coordination. Its first release is a research proof of concept, not a physical robot controller or a certified safety system.

## Quick start (target, not yet implemented)

`docker compose up --build` will start web, API, worker and PostgreSQL.
`make test`, `make demo`, `make demo-scoped`, `make replay` and `make replay-scoped` work for the current core; full Compose and benchmark smoke are planned.

## Current local core (main)

From the repository root with Python 3.12+ and Make:

```bash
make test
make demo
make replay
```

The CLI runs the actual centralized baseline using the two-robot scripted outage fixture, writes `artifacts/demo.json`, and checks the semantic digest on replay. No database or cloud service is needed. Standalone local_auction and web/API services are not implemented yet; scoped_lease is available below. See [progress](docs/progress.md) for the current verification status and limitations.

## Experimental scoped-lease increment (v0.2)

```bash
make test
make demo-scoped
make replay-scoped
```

Runs the same two-robot fixture with fixed, predelegated scope authority and local leader auction rounds. Compare task events during the outage; do not interpret the tiny fixture as a comparative research benchmark. See docs/coordination.md for assumptions and pending renewal/reconciliation work.

## R1 three-policy core (v0.3)
```bash
make test
make demo && make replay
make demo-auction && make replay-auction
make demo-scoped && make replay-scoped
```
The CLI supports three scripted policies. The peer auction is a simplified baseline, and scoped renewal/reassignment are conservative. See docs/coordination.md and docs/progress.md. Web/API/MCP remain planned.

## R2 research benchmark
Install pinned validation dependencies: `python3 -m pip install -r services/swarmforge/requirements-benchmark.txt`. Run `make benchmark-smoke` (12 runs) or `make benchmark-research` (72 runs including the smoke subset). Each run validates the trace and replays the same manifest. Inspect summary.json, runs.csv, comparisons.csv and raw traces in the output directory. Failures retained; no statistical claim from small smoke fixtures.
